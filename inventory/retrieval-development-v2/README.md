# Corpus-v2 development retrieval preregistration

This inventory freezes four generic `java/path-injection` development queries,
their relevance judgments, the admitted corpus identity, the exact BGE-M3
digest, and the strict readiness gate before any output exists.

The primary gate is `Hit@3 = 1.0`. Two independent executions must also
produce canonically identical retrieval records. The judgments were derived
only from the admitted generic corpus sections and contain no OWASP Benchmark
label, target-CVE advisory, patch, or repository-specific answer material.

Passing this gate is development retrieval evidence only. It does not establish
Variant C quality, held-out performance, or benchmark readiness.
